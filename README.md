# 🍽️ Zomato Data Analysis

## 🔍 Overview
This project analyzes Zomato restaurant data to extract insights about restaurant ratings, locations, cuisines, price ranges, and customer preferences. It uses Python-based exploratory data analysis (EDA) to understand food trends and dining patterns.

## ⭐ Features
- Complete exploratory analysis of Zomato dataset
- Restaurant rating distribution study
- Cuisine popularity analysis
- Cost for two insights across cities
- Location-based restaurant performance
- Visual understanding of customer preferences

## 📊 Analysis Highlights
- Top cuisines preferred by users
- Cities with highest number of restaurants
- Relationship between ratings and cost
- Impact of online ordering on ratings
- Restaurant type distribution
- Price category comparisons

## 🧹 Data Cleaning & Preparation
- Handling missing data
- Removing duplicates
- Normalizing text-based fields
- Splitting multi-value cuisine columns
- Extracting numeric values from cost fields
- Preparing data for visualization

## 📈 Visualizations Used
- Bar charts (cities, cuisines, ratings)
- Pie charts (restaurant types, price ranges)
- Histograms (rating distributions)
- Count plots (online order vs rating)
- Box plots (cost vs rating)
- Heatmaps (correlations)

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
